# Contributing

Thanks for your interest in contributing to Uplinkr.

## Before You Start

- Check existing issues and discussions.
- Open an issue for bugs or feature proposals before starting work.

## Development

- Use PHP 8.2 or newer.
- Install dependencies with `composer install`.
- Run the test suite with `./vendor/bin/phpunit`.

## Pull Requests

- Keep changes focused and minimal.
- Update tests and documentation as needed.
- Follow existing CLI output wording and conventions.
